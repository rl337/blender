# N14E newsroom (archive / process reference)

The `Untitled/` tree holds the prior N14E newsroom experiment. It informs
**workflow shape** for Smithy (set vs workshop vs scripts vs previews) but is
**out of scope** for first curated foundry builds.

## MUST

- Treat `Untitled/` as a local archive until an explicit inventory + licence pass.
- Do not import N14E blends, MakeHuman outputs, or Anchor_* scripts into
  `smithy.prop_scaffold` or early library publishes.

## SHOULD

- Borrow process patterns: modular split, review cameras, contact-sheet evidence,
  headless regen, MCP for live inspect.
